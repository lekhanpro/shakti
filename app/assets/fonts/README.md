# Bundled typography

The Android interface uses Manrope for headings and Inter for body text and controls. Both variable fonts are bundled for offline rendering and distributed under the SIL Open Font License 1.1. Their licenses are included in the app's Licenses page.

Official Google Fonts sources (downloaded 22 October 2026):

- [Manrope variable font](https://github.com/google/fonts/blob/main/ofl/manrope/Manrope%5Bwght%5D.ttf) and `OFL-Manrope.txt`.
- [Inter variable font](https://github.com/google/fonts/blob/main/ofl/inter/Inter%5Bopsz,wght%5D.ttf) and `OFL-Inter.txt`.

The previous Poppins and Nunito files remain available to existing project assets.
